# Creator Store Asset Pipeline

We want a polished, cohesive world and will use suitable free Roblox Creator Store assets where their usage terms allow it.

## Intake checklist
1. Record the asset name, Creator Store URL/asset ID, creator, date imported, and license/permission evidence in the asset register.
2. Confirm that the asset is free to use for this experience and that the creator's terms permit the intended use, including monetized publication.
3. Inspect the model hierarchy before placing it in the game.
4. Review every Script, LocalScript, ModuleScript, remote, constraint, attachment, and external dependency. Do not run unknown scripts.
5. Prefer clean models without scripts; implement gameplay behavior ourselves.
6. Check scale, pivot, collision, texture resolution, mesh count, draw calls, and mobile performance.
7. Place the asset in a test scene beside approved reference assets to catch style mismatch.
8. Optimize and document modifications before promoting to the main map.

## Art direction
- Bright, friendly, stylized 3D with consistent proportions.
- Saturated colors balanced by readable materials and clear silhouettes.
- Strong landmark silhouettes; avoid visual noise around interactable eggs.
- Use a consistent lighting, fog, material, and foliage language.
- Egg and companion rarity must remain readable without relying on color alone.
